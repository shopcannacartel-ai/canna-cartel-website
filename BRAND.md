# Canna Cartel 420 brand system

The exact approved original Canna Cartel logo is required. No generated substitute is part of this repository; upload the original to WordPress Site Identity and use that same original in Base44.

| Token | Value | Use |
|---|---|---|
| Forest | `#073E24` | Navigation, hero, footer |
| Leaf | `#2A8E58` | Secondary accent, links |
| Gold | `#C9A34A` | Buttons, emphasis |
| Ivory | `#F5F3EB` | Main background |
| Ink | `#14261E` | Body text |
| White | `#FFFFFF` | Cards, high-contrast content |

System UI sans-serif font for body; Georgia as an editorial headline accent. Container max 1180px. Sections have generous vertical spacing (65–96px). Cards have 20px corners; buttons have pill corners and touch-safe sizes. Natural photographic lighting, soft shadows and no blackening of the logo. Reduced motion is respected.

Images in the `assets/images` folder are *derived* from the user's supplied Cape Town/community photos, for desktop and mobile. Keep originals in your own media archive. Educational charts were not republished verbatim because their medical claims have not been fact checked.
